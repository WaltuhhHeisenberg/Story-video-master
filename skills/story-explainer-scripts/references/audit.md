# Audit: checking a script sentence by sentence

Run this on every draft before delivering, and use it as the main method when the user hands over a script to improve.

## Contents
1. The per-sentence pass
2. Flags and fixes
3. Whole-script checks
4. Audit table format
5. Final checklist

## 1. The per-sentence pass

Number every sentence, then record for each:

- **Pays:** the earlier question it answers (or "none").
- **Opens:** the new question it raises (or "none").
- **Job:** hook, motive, mechanism, escalation, number, human detail, turn, triumph, cost, time jump, coda.
- **Length:** word count, to spot runs of same-length sentences.
- **Source:** the fact-ledger line that supports any figure, date, or name.

## 2. Flags and fixes

| Flag | How to spot it | Fix |
|---|---|---|
| **Dead sentence** | Pays nothing and opens nothing | Cut it, or add a flip, a number, or a consequence |
| **Unpaid hook** | A bare hook with no payoff within about ten sentences | Pay it off or remove the hook |
| **Only-pays sentence at a loop end with nothing open** | A natural exit point | Open the next question in the same sentence |
| **Warm-up** | First sentence lacks a date, number, or outcome | Rewrite using a hook formula |
| **Hidden outcome** | The viewer cannot tell what the story ends in | State the outcome in the first two sentences |
| **Adjective-carried emotion** | Words like "horrifying", "shocking", "insane" doing the work | Replace with the fact that was horrifying |
| **Long triumph** | More than three sentences of celebration | Cut to one to three |
| **Same-length run** | Four or more consecutive sentences within about three words of each other | Vary: add a short verdict or merge two into one longer mechanism sentence |
| **Moral or summary** | Lesson, "the takeaway is", recap of the story | Delete; end on a consequence or institutional statement |
| **Stacked bare hooks** | Two announcements of turns in a row | Separate them with a delayed explainer |
| **Backstory dump** | More than a few sentences of history before the incident | Move history into the motive beat or cut |
| **Unsupported figure** | A number with no ledger entry, or only one weak source | Verify or remove or label as reported |
| **Invented detail** | A quote, scene, or motive not in sources | Remove, or label as dramatization in a production note |
| **Too many threads** | More than one parallel thread in a five-minute script | Cut the weaker thread |
| **Repeated information** | The same fact stated twice without new framing | Cut one |

## 3. Whole-script checks

- **Word count versus runtime:** about 150 words per minute. A long-form script usually lands at 750 to 850 words; a Short at 80 to 150.
- **Number density:** roughly one sentence in four should carry a hard number or date. Much lower reads vague; much higher reads like a ledger.
- **Emotion contrast:** no two adjacent beats should produce the same feeling. Put a quiet, ordinary beat right before a hit.
- **Escalation order:** each cascade step larger in scale than the last, each with a concrete image.
- **Contrast number present** (if the story has one) and placed late.
- **Perspective:** one fair sentence stating the opposing party's logic.
- **Ending:** a consequence or an institution's own words, with no moral and no call to action inside the story.

## 4. Audit table format

When the user asks to see the structure, or when auditing their script, deliver a compact table:

| # | Sentence (short paraphrase) | Pays | Opens | Flag |
|---|---|---|---|---|

Mark only the flagged rows in detail if the script is long; list the rest as "ok." Follow the table with the three highest-impact fixes, in priority order, and the rewritten passages.

## 5. Final checklist

- [ ] Fact ledger exists; every number, date, and name traces to it
- [ ] Allegations and disputed figures are labeled as such
- [ ] The first two sentences pass the hook test (outcome, number, gap, matches title)
- [ ] The expectation is stated before it is broken
- [ ] Each bare hook is paid off within about ten sentences
- [ ] At least one loop is open at every point until the final beat
- [ ] Triumph is one to three sentences
- [ ] The cascade escalates in scale with concrete images
- [ ] The worst fact is stated plainly, once
- [ ] Rhythm varies; no run of four same-length sentences
- [ ] No moral, summary, or in-story call to action
- [ ] No invented dialogue or scenes; dramatizations flagged
- [ ] Wording is original and not mirroring any existing video
- [ ] Word count and estimated runtime reported
